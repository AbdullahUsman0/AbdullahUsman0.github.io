# Abdullah Usman Portfolio

A static portfolio for Abdullah Usman's AI and software projects. It includes a home page and seven short project case studies for RAHATAI, ParityLens, ClientOps AI, SkillSwap, EcoTour, Local SLM Lab, and Wombly. The home page also highlights education, leadership, and achievements.

## Structure

- `dist/index.html` — home page
- `dist/projects/*.html` — project case studies
- `dist/styles.css` — shared responsive styles
- `dist/paritylens.png` and `dist/clientops-architecture.png` — screenshots from the corresponding project repositories

The site uses plain HTML and CSS with no build step. Open `dist/index.html` in a browser or serve the `dist` directory with any static web server. Project descriptions are based on the linked public repositories; the case studies distinguish documented features from prototypes and setup requirements.

The hosted preview is currently private to the owner. The source repository is public.
